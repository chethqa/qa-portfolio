## How to use
1. Choose an application you are authorized to test.
2. Adapt the planned cases to its actual requirements.
3. Execute and mark each case Pass, Fail, Blocked, or Not Run.
4. Log only defects you can reproduce.
5. Import the Postman collection and run it against the configured practice API.
6. Replace placeholders with actual environment details, results, evidence, and conclusions.
